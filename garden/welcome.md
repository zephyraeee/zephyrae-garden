# Welcome to my digital garden

This is the home page: the file `garden/welcome.md`. Replace this text with your
own introduction.

A digital garden is a collection of notes that grow over time. They are linked
to each other instead of being ordered by date, so start anywhere:

- [[writing-posts|How to write a post]] covers front matter, tags and drafts.
- [[linking|Linking notes]] shows how notes point to each other and how the
  graph is built from those links.

Everything about the look of the site, from the colors and fonts to its name and
sections, is changed from the admin page at `/admin`.
